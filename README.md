# Заметки — Flask

## Запуск
    python -m venv venv
    venv\Scripts\activate          # Windows   (Linux/macOS: source venv/bin/activate)
    pip install -r requirements.txt
    python app.py
Открыть http://127.0.0.1:5000

Логотип положите в static/img/logo3.png.
База (data/notes.db) и секретный ключ создаются сами при первом запуске.

Подробное объяснение кода для защиты — в файле РАЗБОР.md
